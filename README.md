# Happy Teachers' Day 🌷
### A Heartfelt Tribute Dedicated to Sarada Madam & Kranti Madam

A warm, personal, and emotional Teachers' Day tribute web application built as an interactive digital surprise.

---

## 🌟 Highlights & Features

- **Dedicated to Two Mentors**:
  - **Sarada Madam** (Our Respected HoD): A regal, leadership-inspired tribute experience featuring soft sparkles, floating floral petals, an unfolding royal letter, and the *"One More Little Surprise ✨"* reveal.
  - **Kranti Madam** (Our Respected Teacher): A warm, nurturing sunflower-inspired experience featuring animated books, an SVG animated pencil drawing a glowing heart, starlight shimmer, and the *"A Little Thought For You 💫"* reveal.
- **Floating Classroom Background**: Gentle, non-distracting SVG animations of books, pencils, stars, hearts, and sparkles.
- **Interactive Mini-Surprises**: Clickable tokens for Apple (Patience award), Book (Wisdom), Lightbulb (Clarity), and Heart (Belief) with smooth toast notifications.
- **"More Than a Teacher" Cards**: Scroll-animated appreciation cards detailing how our teachers guide, care, nurture, and inspire.
- **Atmospheric Quote**: High-contrast editorial reflection with drifting starlight particles.
- **Cinematic Final Section & Celebration**: Interactive reveal of *"Thank You, Teachers. ❤️"* leading into multi-stage elegant confetti and petal celebration.
- **Accessibility & Performance**: Full keyboard navigation, `Escape` key listeners, focus styling, and respect for `prefers-reduced-motion`.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

## ☁️ Deployment to Vercel

The project is pre-configured with `vercel.json` for 1-click zero-configuration deployment:
1. Push this folder to a GitHub repository.
2. Import the repository in [Vercel](https://vercel.com).
3. Click **Deploy**.
